---
title: Plandomizer
---

A plandomizer (often shortened as plando) is a special kind of seed where another person already placed every item manually. These seeds can be anything from gimmicks, challenges, tools or just fun progression ideas.

## Version 4.x plandomizers

Until version 4, plandos are created using the [Header Language](https://docs.google.com/document/d/1IR1DHnbtO8rydCLEgFh-yp3iRkzZbFAG-EmR5hxrfmU/edit). Such plandos will not work in version 5 and later.

You can play the downloaded seeds with a double click if you have v4 as your default installation.

- [Chaos](https://bluespheres.weebly.com/chaos.html) by CosmicAngel, completely randomizes your skills every time you collect a new pickup
- [Fireball](https://bluespheres.weebly.com/fireball.html) by CosmicAngel
- [Kaizo](https://bluespheres.weebly.com/kaizo.html) by CosmicAngel
- [Time](https://bluespheres.weebly.com/time-act-1.html) by CosmicAngel
- [BitbAem!](https://github.com/pizzaspren/BitbAem/tree/v4) by pizza

## Version 5.x plandomizers (beta)

Starting with version 5, plandos are created using the [Seed Language](https://docs.wotw.orirando.com/docs/seedlang/). It's still in development, so plandos might break frequently.

You can play the downloaded seeds with a double click if you have v5 as your default installation. Otherwise, you can place them in your plandos folder ("Open user data directory" on the launcher home page -> "seedgen" -> "plandos") and launch them from the "Plandomizers" launcher tab.

- [It's Dangerous To Go Alone](https://drive.google.com/file/d/1QF0h0zuLP-wiFaRl0P6BnzzmHfODXCgH/view) by Sirius

## Older plandomizers

Some very old plandos require downpatching the randomizer. You can dig up the versions in the [GitHub Releases](https://github.com/ori-community/rando-build/releases).

- [A world without injuries](https://drive.google.com/file/d/1DQTT0dYEjXhBCKXw7gU8lyxFi8J4XUKl/view) for version 1.10.2 by the chinese community (contact Arkadia if needed)
- [Milktown](https://drive.google.com/drive/folders/15rSX6TqJcJsQWFTIC67sygK_I_Dkm34k?usp=sharing) for version 1.6.1 by Justepic
